# Weather Activity Ranker

Enter a city and see how good the next 7 days are for skiing, surfing, outdoor sightseeing and indoor
sightseeing, based on [Open-Meteo](https://open-meteo.com/) forecasts.

Work in progress. See [docs/PLAN.md](docs/PLAN.md) for the plan and
[docs/DECISIONS.md](docs/DECISIONS.md) for the assumptions.
